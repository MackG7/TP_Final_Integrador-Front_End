 ### Tecnologías utilizadas

 **React** – Librería principal para la UI
- **Vite** – Bundler moderno y ultra rápido
- **React Router DOM** – Navegación por rutas (`/chat/:id`, `/contact/:id`)
- **Context API** – Manejo de estado global para contactos y mensajes
- **JavaScript** – Lógica funcional
- **CSS modular** – Estilos separados por componente.

### Estructura de carpetas
src/
├── Assets/
│ └── Icons/ # Íconos en SVG/PNG para la UI
├── Components/
│ ├── Chat/ # Chat principal
│ ├── ContactList/ # Lista de contactos con filtro
│ ├── ContactInfo/ # Detalles del contacto
│ ├── Message/ # Cada burbuja de mensaje
│ └── MessageInput/ # Input de nuevos mensajes
├── Context/
│ ├── MessengerContext.jsx # Estado de contactos
│ └── MessagesContext.jsx # Estado de mensajes
├── Services/
│ └── messagesService.js # Simula una API local de mensajes
├── App.jsx # App principal con rutas
└── main.jsx # Entry point
